# Auth

Fitur login dan register. Kode yang sudah ada berada di `lib/auth/` dan akan dipindahkan bertahap ke folder ini saat pengembangan berikutnya.

Struktur target:

- `screen/` layar login dan register
- `service/` komunikasi API autentikasi
- `repository/` penyimpanan token dan data autentikasi
- `widget/` komponen form autentikasi
